# Practicum_projects
# automated_tests_for_Stellar_Burgers - автотесты регистрации, входа, перехода в личный кабинет и выхода из аккаунта, переходы в разделе "Конструктор" для сервиса Stellar Burgers
# Autotests_for_the_educational_service_“Yandex.Samokat” - автотесты с применением Page Object Model для учебного сервиса «Яндекс.Самокат»
# Tests_of_the_API_of_the_Yandex_Scooter_educational_service - тестирование ручек (создание курьера, логин курьера, создание заказа, список заказов) API учебного сервиса Яндекс Самокат
# Unit_tests_for_Stellar_Burgers - Юнит-тесты (100% покрытие тестами одного из классов с использованием моков и параметризации) для Stellar Burgers
# API_endpoint_tests for_Stellar_Burgers - автотесты для API (тестирование эндпоинтов API на основании документации с выводом отчета в Allure: создание пользователя, создание заказа, входы по логину пользователя) для Stellar Burgers
# UI_testing_for_Stellar_Burgers - автотесты для UI (описание элементов с помощью паттерна Page Object, тестирование функциональности в Google Chrome и Mozilla Firefox с выводом отчета в Allure) для Stellar Burgers
# Manual_testing_for_Yandex_Scooter - проектирование тестов на основании требований и макетов в Figma (составление чек-листа для экрана "Статус заказа", КЭ и ГЗ полей к экрану «Сделать заказ», составление тест-кейсов функциональности и верстки для мобильной версии), тестирование веб-приложения Яндекс Самокат в 2-х окружениях, составление баг-репортов
